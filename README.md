# 🧹 Housekeeping Stock Count Website

ഹൗസ്കീപ്പിംഗ് ഡിപ്പാർട്ട്‌മെന്റിലെ സ്റ്റോക്ക് എണ്ണാനും (Stock Counting), എല്ലാ ജീവനക്കാർക്കും (Staff) ഫോണിലും കമ്പ്യൂട്ടറിലും ഒരേ സമയം തത്സമയം (Real-time Sync) കാണാനും ഉപയോഗിക്കാൻ കഴിയുന്ന ആധുനിക വെബ്സൈറ്റ്.

നിങ്ങൾ നൽകിയ ഡിസൈൻ കൃത്യമായി അതേ കളർ തീമിലും ലേഔട്ടിലും തയ്യാറാക്കിയിട്ടുണ്ട്.

---

## 🚀 How to Run (എങ്ങനെ പ്രവർത്തിപ്പിക്കാം)

### ഓപ്ഷൻ 1 (ഏറ്റവും എളുപ്പം):
ഫോൾഡറിലുള്ള **`start.bat`** ഫയലിൽ ഡബിൾ ക്ലിക്ക് ചെയ്യുക. സെർവർ സ്റ്റാർട്ട് ആയി ബ്രൗസറിൽ വെബ്സൈറ്റ് സ്വയം തുറക്കും.

### ഓപ്ഷൻ 2 (Terminal വഴി):
ഈ ഫോൾഡറിൽ powershell അല്ലെങ്കിൽ command prompt തുറന്ന് താഴെ പറയുന്ന കമാൻഡ് നൽകുക:
```bash
node server.js
```
തുടർന്ന് ബ്രൗസറിൽ `http://localhost:3000` തുറക്കുക.

## 📱 എല്ലാ ഹൗസ്കീപ്പിംഗ് ജീവനക്കാർക്കും ഫോണിൽ കണക്ട് ചെയ്യാൻ (Mobile Access for All Staff)

എല്ലാ ഹൗസ്കീപ്പിംഗ് ജീവനക്കാർക്കും അവരുടെ മൊബൈൽ ഫോണിലോ ടാബ്‌ലെറ്റിലോ ഈ സൈറ്റ് തുറന്ന് സ്റ്റോക്ക് അപ്‌ഡേറ്റ് ചെയ്യാം:

1. ജീവനക്കാരുടെ ഫോണും കമ്പ്യൂട്ടറും ഒരേ Wi-Fi നെറ്റ്‌വർക്കിൽ കണക്ട് ചെയ്യുക.
2. വെബ്‌സൈറ്റിലെ മുകൾ ഭാഗത്തുള്ള **`📱 Connect Phones`** ബട്ടണിൽ ക്ലിക്ക് ചെയ്യുമ്പോൾ വരുന്ന **QR Code** ജീവനക്കാർക്ക് ഫോൺ ക്യാമറ വെച്ച് സ്കാൻ ചെയ്യാം.
3. അല്ലെങ്കിൽ സ്ക്രീനിൽ കാണിക്കുന്ന Wi-Fi ലിങ്ക് (ഉദാഹരണത്തിന്: `http://192.168.1.40:3000`) ഫോണിലെ Chrome / Safari ബ്രൗസറിൽ ടൈപ്പ് ചെയ്യുക.
4. ഏതെങ്കിലും ജീവനക്കാരൻ ഒരു ഐറ്റത്തിന്റെ കൗണ്ട് സേവ് ചെയ്താൽ, മറ്റെല്ലാ സ്റ്റാഫിന്റെ ഫോണുകളിലും കമ്പ്യൂട്ടറിലും സെക്കൻഡുകൾക്കുള്ളിൽ അത് ഓട്ടോമാറ്റിക് ആയി അപ്‌ഡേറ്റ് ആകും (Real-time Live Sync).

## 📋 ഉൾപ്പെടുത്തിയിരിക്കുന്ന പ്രധാന ഫീച്ചറുകൾ

1. **Exact UI Design**: നിങ്ങൾ നൽകിയ സ്ക്രീൻഷോട്ടിലെ ഡാർക്ക് മോഡ് തീം, കാർഡുകൾ, ഫോണ്ടുകൾ, നിറങ്ങൾ എല്ലാം അതുപോലെ തന്നെ രൂപകൽപ്പന ചെയ്തിട്ടുണ്ട്.
2. **Dashboard Summary Cards**:
   - `12` Items tracked
   - `12` To count now
   - `0` Total stock (min 500)
3. **Smart Warning Box**:
   - `13 warnings` അലേർട്ട് ബോക്സ്.
   - മിനിമം 500 സ്റ്റോക്ക് തികയാത്തതിനാലും, എണ്ണാൻ ബാക്കിയുള്ള ഐറ്റങ്ങൾക്കും പ്രത്യേകം വാർണിംഗ് ബുള്ളറ്റുകൾ.
   - ഓരോ സാധനവും എണ്ണി സേവ് ചെയ്യുമ്പോൾ വാർണിംഗ് ലിസ്റ്റിൽ നിന്ന് അത് ഓട്ടോമാറ്റിക് ആയി മാറും.
4. **Items Categories**:
   - **Cleaning supplies**: Broom, Mop, Gloves, Cleaning chemicals, Toilet roll, Restaurant tissue.
   - **Guest amenities**: Dental kit, Shaving kit, Shower cap, Soap, Shampoo, Moisturiser.
5. **Staff Name Tracker**:
   - മുകളിലുള്ള 👤 Staff ബട്ടൺ വഴി സ്റ്റാഫിന്റെ പേര് (Priya, Rahul etc.) നൽകാം. ആര് എപ്പോൾ സ്റ്റോക്ക് എടുത്തു എന്ന് കൃത്യമായി രേഖപ്പെടുത്തപ്പെടും.
6. **Add New Items**: ഹൗസ്കീപ്പിംഗിലേക്ക് പുതിയ സാധനങ്ങൾ (ഉദാ: Bath towel, Slippers) ചേർക്കാൻ `➕ Add Item` ബട്ടൺ.
7. **Report & CSV Export**: സ്റ്റോക്ക് കണക്കുകൾ പ്രിന്റ് എടുക്കാനും എക്സൽ / CSV ഫയലായി ഡൗൺലോഡ് ചെയ്യാനും `📋 Report` ബട്ടൺ.
8. **Shift Reset**: അടുത്ത ദിവസത്തെ അല്ലെങ്കിൽ അടുത്ത ഷിഫ്റ്റിലെ കൗണ്ടിംഗിനായി ഒറ്റ ക്ലിക്കിൽ റീസെറ്റ് ചെയ്യാനുള്ള ഓപ്ഷൻ.
